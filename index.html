JavaScript가 하는 일 체험하기

HTML이 웹사이트의 뼈대라면, JS는 웹사이트에 생명을 불어넣습니다.
아래 버튼을 눌러 각각의 하위 페이지에서 실제 작동하는 기능을 테스트해 보세요!

기능 01

화면 및 디자인 실시간 제어 (DOM 조작)

JS가 HTML 태그의 클래스와 스타일을 실시간으로 바꾸는 기능입니다.

다크 모드 전환

전체 테마 색상을 반전시킵니다.

박스 색상 랜덤 변경

아래 미리보기 박스의 색상을 바꿉니다.

버튼을 눌러 제 색깔과 글자를 바꿔보세요!

기능 02

실시간 자동 견적 계산기

사용자가 숫자를 입력하거나 옵션을 선택하는 즉시 JS가 수학 연산을 수행합니다.

기본 합계: 30,000원
할인 금액: - 0원
최종 결제 금액: 30,000원
기능 03

동적 요소 추가/삭제 (To-Do 리스트)

HTML 파일에 미리 적어두지 않은 새로운 항목을 JS가 실시간으로 생성하고 지웁니다.

기능 04

외부 서버(구글 시트) 통신 원리

깃허브 웹페이지에서 입력한 데이터를 구글 앱스 스크립트(.gs)로 전송하거나, 외부 API 데이터를 불러오는 과정입니다.
